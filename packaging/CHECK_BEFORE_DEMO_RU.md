# Проверка полного комплекта BeeGo

Проверяй распакованную копию на **Windows x64**. Для нового расчёта нужны
Python 3.13 x64 и запущенный Docker Desktop. Узлы Node.js, зависимости сайта,
Python wheel-файлы, образ Valhalla, дорожные тайлы, GTFS и исходники МЦК/МЦД
лежат внутри архива. Для геокодирования новых адресов и получения ещё не
сохранённого расписания нужен интернет и доступная квота внешних API.

## 1. Целостность архива

- [ ] Сравни SHA-256 ZIP с файлом `BeeGo_COMPLETE_2026-09-28.zip.sha256`,
  лежащим **рядом** с ZIP: `Get-FileHash .\BeeGo_COMPLETE_2026-09-28.zip -Algorithm SHA256`.
- [ ] Распакуй ZIP полностью на диск с несколькими свободными гигабайтами.
- [ ] Из корня распакованного проекта выполни `python VERIFY_PACKAGE.py`.
  Успех: все файлы совпадают с манифестом, 181 историческая дата, 0
  незакрытых аварий в опубликованной истории.
- [ ] Убедись, что нет `algorithm/work/dataset_v21`, `tmp` и старых
  альтернативных исходных наборов 17 августа. Основной вход: `data/dataset`.

## 2. Подъём сервисов

- [ ] Выполни `powershell -ExecutionPolicy Bypass -File .\START_BEEGO.ps1`.
  При первом запуске установка Python-пакетов из архива может занять минуты.
- [ ] `http://127.0.0.1:8002/status` отвечает JSON Valhalla.
- [ ] `http://127.0.0.1:5173/` открывает сайт; локальный API слушает 8787.
- [ ] Если один из сервисов не поднялся, смотри `runtime/portable-*.stderr.log`
  и `docker logs beego-handoff-valhalla`. Не подменяй точные маршруты
  приблизительными, если Valhalla не работает.
- [ ] Файлы `site/.dev.vars` и `.env.routing.local` содержат имена ключей
  `GEOAPIFY_API_KEY`, `YANDEX_RASP_API_KEY`, `DGIS_ROUTING_API_KEY`.
  Значения никому не отправляй и не выкладывай архив в публичный GitHub.

## 3. Опубликованный план и история

- [ ] На 17 августа 2026 сайт показывает **205/205**, 32 бригады и 0
  нарушений. `algorithm/artifacts/current/initial-exact-205-of-205-retimed.json`
  имеет `EXACT_VALID`, а независимая проверка — `VALID`.
- [ ] Запусти из корня `& .\offline-assets\node\node.exe
  site\scripts\verify-algorithm-integration.mjs`. Успех: начальный план
  205/205, контрольное событие 206/206, оба точные и проверенные.
- [ ] В аналитике доступно 182 дня (17 февраля — 17 августа), включая 181
  исторический набор в `history/`. Для каждого дня есть точный FCFS-бейзлайн;
  опубликованные аварии назначены. Не требуй 100% обычных заявок на каждом
  историческом дне: их объём намеренно различается.

## 4. Новый день и ошибки загрузки

- [ ] Загрузи корректный новый день в пределах трёх районов, добавив новый
  адрес без координат. Geoapify должен вернуть конкретную точку или понятную
  ошибку с адресом, если его нельзя уверенно распознать.
- [ ] Добавь заявку с требованием общественного транспорта. Проверь, что
  индекс GTFS/метро/МЦК/МЦД построен **для выбранной даты**, а итоговый
  маршрут прошёл точную проверку. При отсутствии рейсов либо исчерпании
  квоты расчёт должен объяснить, чего не хватает, а не подставить автомобиль.
- [ ] Проверь `EXACT_VALID`, `validation.status=VALID`, 0 нарушений времени,
  навыков, оборудования, транспорта и смены. Окно ограничивает **прибытие**;
  работа может закончиться после окна, если другие ограничения соблюдены.
- [ ] Загрузи намеренно неверные данные: сломанную дату, пустой адрес без
  координат и неизвестный вид транспорта. Система должна показать конкретную
  ошибку ввода, а не молча придумать значения или опубликовать такой план.
- [ ] Для сложного дня убедись, что интерфейс завершает попытку в пределах
  15 минут с проверенным результатом либо явной ошибкой. Если авария осталась,
  `UNRESOLVED` означает предел поиска, а не доказательство невозможности.

- [ ] Перезапусти прямые Node-тесты сайта и сборку Vite, указанные в
  `HANDOFF_FOR_AGENT_RU.md`; при подготовке архива прошли 69 тестов сайта.
- [ ] Перезапусти профильные Python-тесты алгоритма; при подготовке прошёл
  41 тест. Старые исследовательские тесты, привязанные к исключённому
  усложнённому набору, перечислены в документе передачи.
- [ ] После изменения входных данных пересчитай маршруты и заново проверь
  опубликованный артефакт. Нельзя менять время или путь после валидации.

Планы показывают результат **модели**, а не фактическое исполнение бригадами.
Для будущей даты покрытие зависит от реальных заявок, ресурсов, дорог и
расписания; 205/205 относится только к выбранному набору 17 августа.
