# Планировщик и маршрутизация

Python-часть рассчитывает назначения, порядок визитов, точные поездки и изменения оставшегося дня. Каждый публикуемый план проходит независимую проверку.

| Каталог | Содержание |
| --- | --- |
| `src/beeline_planning/` | Ограничения, CP-SAT, локальный поиск, перепланирование и проверка |
| `src/beeline_routing/` | Дороги, расписания, метро и проверка транспортных ограничений |
| `tools/` | CLI-конвейеры, установка индекса, генерация наборов и воспроизведение расчётов |
| `tests/` | Регрессионные проверки алгоритмов и контрактов |
| `artifacts/` | Проверенные входные примеры и планы, используемые приложением и тестами |

Установка зависимостей:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r algorithm/requirements-full.txt
```

Команды выполняются из корня репозитория. Для Windows используется `.venv/Scripts/python.exe`. Полный контейнерный запуск устанавливает окружение автоматически.

Правила расчёта описаны в [планировании](../docs/reference/planning.md), транспорт — в [маршрутизации](../docs/reference/routing.md), данные — в [каталоге](../docs/reference/data-catalog.md). Команды тестов находятся в [руководстве разработки](../docs/development/contributing.md).

`artifacts/complexity/initial-exact.json` связан с актуальными переменными длительностями. `artifacts/current/` содержит базовые примеры для воспроизведения и регрессий; их числа не заменяют результат текущей модели. `artifacts/tz3/home-starts/` содержит проверенный сценарий домашних стартов с собственным манифестом. Новые расчёты сохраняются в игнорируемый `runtime/`, а не рядом с исходными примерами.
