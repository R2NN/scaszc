28 бригад: независимый валидатор вернул `VALID`, нарушений нет. Новый
screening-план не проходил exact-маршрутизацию; его
`publication_allowed` остаётся `false`. Команда для проверки любого
совместимого датасета:

```powershell

python tools\validate_screening_solution.py --dataset ..\data\dataset `
  --scenario core --screening-root ..\data\screening `
  --candidate D:\runs\screening.json
```

фиксированного числа районов. Автотест CP-SAT и независимого
