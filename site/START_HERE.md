# BeeGo!

Текущие инструкции для сдачи и запуска находятся в [корневом README](../README.md). Для локальной разработки сайта используйте `pnpm install --frozen-lockfile` и `pnpm run dev -- --host 127.0.0.1 --port 5173`; API отдельно запускается командой `pnpm run dev:api` из каталога `site`.

Проверенные демонстрационные планы и документация алгоритма находятся в репозитории. Для нового точного расчёта нужны офлайн-данные и Valhalla согласно [инструкции стенда](../deploy/README_RU.md).
