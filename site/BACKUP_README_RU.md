# Резервная копия BeeGo / LCT Web

Эта папка содержит рабочий сайт BeeGo вместе с интегрированными аналитикой,
точным алгоритмом планирования, моделями, исходными данными и локальным
Valhalla runtime.

## Быстрый запуск

1. Распакуйте архив в папку без ограничений на запись.
2. Откройте PowerShell в корне проекта.
3. Выполните `./START_SITE.ps1`.
4. Откройте `http://127.0.0.1:5173/`.

Если зависимости Node.js ещё не установлены, скрипт установит их по
`package-lock.json`. Локальные секреты намеренно не входят в резервную копию:
при необходимости создайте `.dev.vars` из `.dev.vars.example`.

## Что входит в копию

- исходники frontend и Cloudflare Worker (`src`, `worker`, `public`);
- production-сборка (`dist`);
- точный Python-планировщик и тесты (`algorithm`);
- наборы данных, маршруты и транспортные матрицы (`data`);
- Valhalla runtime и офлайн-карты (`runtime`, `valhalla-data`);
- CatBoost-модель и 180-дневная аналитическая история (`models`, `public/data`);
- исходные материалы передачи (`source_materials`);
- документация и инструкции интеграции.

## Что исключено из ZIP

- `node_modules` — восстанавливается командой `npm install`;
- `.git` — история Git не требуется для запуска;
- `.dev.vars` — может содержать локальные секреты;
- `__pycache__`, `.pytest_cache`, `.vite` — воспроизводимые кэши.

Контрольные проверки перед упаковкой:

- production-сборка Vite;
- проверка точных планов `205/205` и `206/206` на 28 активных бригадах;
- 37 тестов аналитики;
- 14 тестов веб-адаптера;
- 5 тестов карты и 24 теста импорта/перепланирования;
- 108 Python-тестов (ещё 2 корректно пропущены).

Подробности архитектуры и порядка работы находятся в `START_HERE.md`,
`AGENT_STARTUP_RU.md`, `HANDOFF_INTEGRATION_GUIDE.md`, `DATA_CATALOG.md` и
`docs/algorithm-integration.md`.
