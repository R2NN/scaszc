## Локальный запуск

Нужны Node.js 20+ и зависимости из `pnpm-lock.yaml`. Из этого каталога:

```powershell
pnpm install --frozen-lockfile
pnpm run dev:api
```

В другом терминале:

```powershell
pnpm run dev -- --host 127.0.0.1 --port 4174
```

Откройте `http://127.0.0.1:4174/`. Для **новых** точных расчётов нужны Python-зависимости алгоритма, локальная Valhalla и транспортные данные; запуск одного Vite недостаточен. [Порядок подготовки стенда](../deploy/README_RU.md) описан отдельно.

## Что проверять

```powershell
pnpm run build
pnpm run test:algorithm
pnpm run test:sites
node --test tests/planning-slot.test.mjs tests/shift-operations.test.mjs
```

Контрольный опубликованный день 17.08.2026 содержит 205/205 назначений. Недельный комплект МЦК/МЦД позволяет собрать транспортный индекс для другого дня недели, но его снимки являются эталонами, а не точным историческим расписанием. Сводная аналитика охватывает 182 дня; операционный архив на стенде есть только для 17.08.2026. Подробности — в [документации по данным](../docs/data.md).

API допускает публикацию лишь проверенного плана (`EXACT_VALID`, `publicationAllowed=true`, `validation.status=VALID`). Один процесс принимает только один тяжёлый расчёт за раз; второй запуск получает `429 PLANNING_BUSY`, просмотр страниц продолжается.
