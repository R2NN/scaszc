# BeeGo!

Полная рабочая версия диспетчерского сайта BeeGo!: React-интерфейс, локальный API, точные опубликованные планы, новый Python-планировщик, аналитика, CatBoost-прогноз, исходные данные и офлайн-маршрутизация Valhalla.

## Быстрый запуск на Windows

Требуется Node.js 20 LTS или новее. После распаковки архива откройте PowerShell в корне проекта и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\START_SITE.ps1
```

Скрипт при необходимости выполнит `npm ci`, запустит backend и frontend, проверит оба сервиса и откроет сайт.

- frontend: `http://127.0.0.1:5173/`
- backend health: `http://127.0.0.1:8787/api/health`

Локальный ключ Geoapify не входит в архив. Он нужен только для геокодирования новых адресов; создайте `.dev.vars` по образцу `.dev.vars.example`.

## Ручной запуск

В двух окнах PowerShell из корня проекта:

```powershell
npm ci
npm run dev:api
```

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

## Проверка

```powershell
npm run build
npm run test:sites
npm run test:algorithm
npm run test:analytics-history
npm run test:map
```

Контрольные опубликованные результаты: исходный точный план — `205/205` на 28 бригадах; после аварии — `206/206` на тех же 28 бригадах. Оба имеют `EXACT_VALID`, независимый `VALID` и `publication_allowed: true`. Сравнение в аналитике также использует отдельный `EXACT_VALID` FCFS-бейзлайн на том же Valhalla/транспортном стеке и с тем же валидатором; прямая с коэффициентом и фиксированные скорости не используются. Новый загруженный набор проходит полный точный pipeline перед публикацией. Событийный пересчёт использует реальные маршруты и независимую проверку; его поиск ограничен бюджетом и не заявляет доказанную глобальную оптимальность.

Точный FCFS закрывает 104/205 заявок на 35 бригадах. На текущей контрольной смене оптимизатор закрывает на 101 заявку больше, использует на 7 бригад меньше и уменьшает средний пробег на визит на 22,4%. Денежные показатели аналитики являются оценкой по настраиваемым тарифам; для исторических синтетических дат без проверенного FCFS сравнение не показывается.
