# BeeGo! — интерфейс и API

Продукт и экраны — в [главном README](../README.md), навигация — в [документации](../docs/README.md).

| Каталог | Содержание |
| --- | --- |
| `src/` | React, постоянная MapLibre-карта, панели и контракты представления |
| `server/` | Node API, SQLite, расчётные операции, PDF и интеграции |
| `scripts/` | Сборка, разработка, резервирование, модели и браузерные проверки |
| `tests/` | Автоматические проверки API, UI-контрактов и данных |
| `public/` | Статика, модели сводок, справка и скачиваемые примеры |
| `models/` | Обученная модель прогноза спроса |
| `worker/`, `.openai/` | Контракт альтернативной поставки приложения |

Рекомендуемый полный запуск — [Docker Compose](../docs/operations/quickstart.md). Настройка Node/Python, команды сборки и тестов — в [руководстве разработки](../docs/development/contributing.md).

Используются pnpm и `pnpm-lock.yaml`. Рабочая база, кэши и ключи не входят в исходники. Контрольные цифры, выполненные проверки и условия внешних сервисов описаны в [проверке платформы](../docs/development/validation.md) и [области применения](../docs/reference/limitations.md).
