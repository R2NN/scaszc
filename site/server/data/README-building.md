# Геометрия зданий

`building-osm.json` — снимок публичных объектов OpenStreetMap, запрошенных по точным `geocode_object_id` исходного набора. Это не новая геокодировка адресов и не данные Билайна об оборудовании.

- 177 контуров зданий, 172 с `building:levels`, 385 точек входов.
- Сохранены оригинальные теги, геометрия и дата актуальности ответа Overpass.
- Источник: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright).
- Остальные объекты используют явно обозначенную условную геометрию. Неизвестная этажность не выдаётся за измеренную.
- Входы на контуре не гарантируют полную нумерацию подъездов. Число модельных секций учитывает эти сведения, размеры здания и устойчивые связи существующего реестра; его можно уточнить.
- Внутренняя планировка, стояки и этажные коробки не извлекаются из OSM. Они показаны как условная схема. Только существующие связи реестра используются для заявок и истории работ.

Приложение читает локальный снимок. Оно не посылает массовые запросы при открытии паспортов.

Явное обновление снимка из каталога `site`:

```powershell
node scripts/enrich-building-data.mjs public/test-data/beego-algorithm-initial.json server/data/building-osm.json
```

Новый набор должен содержать `jobs`, `orders` или `requests` и поле `geocode_object_id`/`sourceData.geocode_object_id` в формате `way/123`. Для здания без такого идентификатора параметры можно внести в редакторе или загрузить через JSON-шаблон.
