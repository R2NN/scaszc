# История и управленческая аналитика

Актуальная карта данных и ограничения: [docs/data.md](../../docs/data.md). Пользовательский смысл экранов: [docs/product.md](../../docs/product.md).

`public/data/analytics-history.json` содержит **182** смены с 17.02 по 17.08.2026. Предыдущие дни имеют отдельные синтетические входные наборы и рассчитанные планы; это не записи о фактически исполненных выездах. У контрольного дня нет выдуманного факта. `actual: null` означает «факт неизвестен».

На демонстрационном сервере полный набор файлов для операционного воспроизведения есть только для 17.08.2026. Графики остальных дней доступны из сводного JSON; без исходных каталогов `history/<date>/` их нельзя открыть как полноценные смены или перепланировать.

## Содержание файла

- `period.start`, `period.end` — включённые границы периода;
- `days[]` — дни с заявками, бригадами, планом, возможными фактическими отметками и происхождением;
- `orders[]` — ID, территория, навык, окно, длительность и другие поля;
- `team[]` — ID, навыки и границы смены;
- `plan.routes[].assignments[]` — порядок, прибытие, начало и завершение работ, расстояние;
- `plan.unassigned[]` — очередь с причинами;
- `actual.visits[]` — введённые отметки, если они существуют.

Показатели строятся из данных выбранного периода и территории: покрытие, очередь, время, загрузка, план-факт, сравнение полных календарных недель. Прогноз спроса и финансовая оценка являются моделями: интервал прогноза и ставки нужно читать вместе с допущениями. Отсутствие факта не трактуется как невыполнение работы.

Проверки аналитики: `pnpm run test:analytics-history` из каталога `site/`. Исторический источник и условия повторного расчёта описаны в [серверном хранилище](../server/baseHistoryStore.mjs).
