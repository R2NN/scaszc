# Обозначения импортируемых заявок

Приложение сохраняет исходные значения файла в `sourceData`. Понятные подписи в интерфейсе не изменяют исходный CSV, JSON, XLS или XLSX.

| Исходное значение | Подпись в интерфейсе | Цвет точки |
| --- | --- | --- |
| `Авария`, `EMERGENCY`, аварийный тип работ | Аварийная заявка | Красный |
| `INSTALL`, `Заявка на подключение`, `Подключение` | Подключение | Жёлтый |
| `Нет линка`, `NO LINK` | Нет связи | Синий |
| `DIAGNOSTICS`, `Диагностика`, `Конвергенция абонента` | Исходное русское название или Диагностика | Синий или жёлтый при требуемом навыке «Подключение» |
| `IP-адрес 169...`, `Разрывы`, `Рост ошибок на порту`, `Низкая скорость`, `Работа с кабелем`, `Мониторинг` | Исходное название | Синий |
| `TVE/ENT. Другие ошибки` | Исходное название | Синий |
| `EQUIPMENT`, `Замена оборудования`, `Дозаказ` | Работа с оборудованием | Фиолетовый |
| `Информация`, `INFORMATION` | Информационная заявка | Зелёный |
| Остальные значения | Исходное название | Зелёный |

Поле оборудования не определяет цвет точки. Например, обычная заявка с требованием `Аварийный комплект` не считается аварией.

## Территории

Локальный каталог содержит 12 административных округов Москвы и 146 районов, поселений и городских округов. Для каждого объекта хранится реальный полигон. Варианты `Восток`, `ВАО`, `EAST` и `Восточный административный округ` связываются с одной территорией.

Условные категории из таблицы, например `Югоцентр` или `Восток-1`, не получают выдуманную границу. Приложение фильтрует их по точному значению из файла и показывает в кадре все точки выбранной категории.

Территории Московской области, которых нет в московском каталоге, например городской округ Кашира, загружаются через Nominatim и проходят проверку попадания точек внутрь полигона.

Для повторной проверки используется команда:

```text
npm run test:territories
```
