# Материалы справки BeeGo!

Инструкции находятся в `src/helpGuides.js`, интерфейс справки — в `src/HelpCenter.jsx`.
Изображения — реальные скриншоты локального сайта на сохранённом дне 17.08.2026.
`workspace-tour.webm` — запись реальных кликов по маршруту, заявке и режимам карты;
`workspace-tour.vtt` содержит русские подписи. Видео загружается только при воспроизведении.

При изменении интерфейса обновляйте скриншоты и запись вместе с шагами инструкций.
Перед захватом дождитесь окончания переходов, загрузки данных и карты.
Для раздела «Ограничения» снимайте верхнюю часть с плашкой предпросмотра;
блок нормативов находится ниже в общем скролле.
