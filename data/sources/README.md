# Исходные материалы

Первичные требования, нормативы, уточнения и обезличенные данные организаторов сохранены без изменения. Они позволяют сопоставить продуктовые решения с постановкой и проверить происхождение норм.

Основные документы — `условие задачи.md`, `3. Билайн Бизнес.pdf`, `Ответы на вопросы.pdf` и `Нормативы.xlsx`. Организационные материалы находятся здесь же и не участвуют в запуске приложения.

Нормализованный вход алгоритма расположен в `data/dataset/`, дополнение с переменной длительностью — в `data/object-complexity/`. Полная навигация — [каталог данных](../../docs/reference/data-catalog.md).
