# Данные BeeGo!

| Каталог | Назначение |
| --- | --- |
| `dataset/` | Нормализованные заявки, состав, навыки, оборудование и правила контрольного набора |
| `object-complexity/` | Дополнение с переменной длительностью и его проверяемый набор |
| `runtime-bundle/` | Части дорожного графа, транспортного индекса и исходников с SHA-256 |
| `transit/` | Манифесты транспорта и недельные снимки железной дороги |
| `screening/` | Поисковые матрицы; не заменяют точную проверку маршрута |
| `traffic4cast/` | Публичная модель временного профиля движения |
| `original_extract/` | Извлечённые исходные таблицы для сопоставления с входами |
| `fixtures/` | Эталонные входы регрессионных тестов с неизменными контрольными суммами |
| `sources/` | Первичные требования, нормативы и обезличенные материалы организаторов |

Основное описание — [каталог данных](../docs/reference/data-catalog.md). Правила использования внешних источников — [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md).

Не редактируйте вручную файлы, включённые в `CHECKSUMS.sha256`, и не меняйте их переводы строк. Рабочие транспортные SQLite создаются установщиком и не входят в Git; операционные базы, ключи и пользовательские резервные копии также хранятся отдельно.
