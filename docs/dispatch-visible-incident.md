# Видимость новой аварии

Убрана плашка «Ожидаем решения · реальное время ×1» из нижней шкалы. Фактическое значение скорости ×1 и временное замедление сохранены.

До исправления отдельный маркер создавался только при открытии уведомления, а фокус был одноразовым событием, которое можно было потерять до подключения карты. Новый ожидающий вызов теперь получает маркер и приближение сразу при получении серверного состояния, независимо от открытия уведомления. По последнему требованию при поступлении аварии левая панель автоматически переходит на вкладку «Аварии», не дожидаясь окончания поиска вариантов. Повторный опрос не открывает закрытую оператором панель заново. Один и тот же вызов не приближает карту при каждом опросе.

Событие фокусировки сохраняется до подключения карты и повторяется после загрузки стиля. Переход в другой раздел или новая сессия очищает сохранённый фокус. Выбор кандидата тоже восстанавливает маркер аварии по его координатам. При фокусировке другой аварии очищается прежнее сравнение маршрутов, чтобы старый маршрут не мешал новому адресу.

Регрессионные проверки покрывают получение аварии без клика по уведомлению, отсутствие повторных перемещений при опросе, получение до готовности карты, восстановление после загрузки стиля, очистку и показ маркера при выборе варианта. Рендер шкалы проверяет отсутствие плашки при сохранённом значении ×1.

Все 315 тестов Node прошли. Production-сборка прошла. HTTP-проверка подтвердила отдачу финальных HTML/JS на порту 4200 и отсутствие удалённого текста плашки.

Автоматическое открытие панели проверено отдельно: 14 целевых проверок прошли, production-сборка успешна, новая версия отдается на порту 4200. Новый ожидающий вызов открывает панель ещё до готовности кандидатов; последующие состояния того же вызова и старые принятые решения повторно её не открывают.

Визуальная проверка не подтверждена: браузерный инструмент ранее отклонил доступ к localhost политикой безопасности и запретил обход.
