# Проверка платформы

Общая приёмка выполнена 20.10.2026 на объединённой версии приложения. Проверялись основные рабочие сценарии и регрессионные наборы; изменяющие действия выполнялись на отдельной базе. Рабочие планы и пользовательская история сохранены.

## Автоматические проверки

| Набор | Результат |
| --- | --- |
| JavaScript / Node | 481 прошёл, 2 пропущены |
| Python | 287 прошли, 2 пропущены |
| Сборка | Клиент и серверный пакет собираются |
| API и runtime | Проверки здоровья и готовности прошли |
| Упаковка релиза | 4 проверки восстановления контрольных сумм прошли |
| Комплектность | Проверены 115 файлов наборов, 12 частей runtime и сжатые входы домашнего сценария |

Основной Python-набор запускается без необязательного Traffic4Cast-теста, требующего `h5py`. Команды воспроизведения — в [руководстве разработки](contributing.md).

Сборка и оба общих набора повторно выполнены в самостоятельном Docker-образе без доступа к прежним рабочим каталогам. Временный экземпляр с новой SQLite открыл заявки и 34 маршрута, реестр инженеров, рейтинг, три сетевых события, формулу длительности, схему здания и аналитику. API готов к точной маршрутизации; ошибок JavaScript при этом просмотре нет. Рабочий экземпляр приложения для этой проверки не менялся.

## Рабочие сценарии

- Импорт, заявки, инженеры, маршруты, перепланирование, версии, фактические отметки и PDF доступны в общей платформе.
- Отзыв привязывается к подтверждённому исполнителю визита, независимо от переданного клиентом ID. Повторный отзыв и оценка незавершённого визита отклоняются.
- Расширенный рейтинговый состав проходит предложение, подтверждение и настоящий расчёт маршрутов. Проверенный результат — 203/205 с 34 используемыми специалистами; глобальная минимальность не утверждается.
- Разные факторы одной работы дают разные расчётные длительности. Проверены серверные оценки 70 и 155 минут, а также отображение формулы 30 + 12 + 14 + 10 = 66 минут.
- Домашние старты отображаются у двух существующих специалистов. Авария сохраняет выбранного инженера; в варианте «После текущей работы» начатая работа завершается до выезда.
- Дорога в 09:30 и метро в 14:25 появляются на общей карте и получают независимо проверенные обходы. Транспорт инженера сохраняется.
- Ручное ограничение выбирается по реальной дороге либо станциям метро. Сохранение доступно при готовом выборе без дополнительного обязательного нажатия «Готово».
- Паспорт, схема здания, длительность, отзывы, сетевые зависимости, аналитика и 19-страничный PDF проверены в браузере.

Это разные версии и входы; их показатели не следует смешивать. Все 41 актуальных снимка сохранены в 1920×1080. В основном README используются 36 экранов, две страницы PDF и пять поясняющих схем.

Сохранность операционной базы проверялась сравнением таблиц и сессий до и после обновления. Изменились только технические якоря часов; планы, факты, отзывы и история остались прежними. Полные локальные логи и резервные копии хранятся вне репозитория.

[Область применения и внешние интеграции](../reference/limitations.md) описаны отдельно. Компоненты без настроенных ключей не считаются проверенными внешними сервисами.
