# Разработка и проверки

## Окружение

Для полного запуска используйте [Docker Compose](../operations/quickstart.md). Для разработки интерфейса нужны Node.js от 22.13 и pnpm 11.25.0; версия закреплена в `site/package.json`. Python-зависимости закреплены в `algorithm/requirements-full.txt`, отдельная модель прогноза — в `site/requirements-ml.txt`.

Из `site/`:

```bash
pnpm install --frozen-lockfile
pnpm run dev:api
```

В другом терминале из того же каталога:

```bash
pnpm run dev -- --host 127.0.0.1 --port 4174
```

Vite показывает интерфейс; новые точные расчёты используют Python, Valhalla и транспортный индекс. Подготовка этих ресурсов описана в инструкции полного запуска.

## Проверки

До запуска проверьте комплектность без сторонних зависимостей: `python tools/check_repository.py` из корня. Затем выполняйте сборку и тесты ниже.

Из `site/`:

```bash
pnpm run build
pnpm test
pnpm run test:algorithm
pnpm run test:sites
```

Из корня, с установленными Python-зависимостями:

```bash
PYTHONPATH=algorithm/src:algorithm/tools:. python -m pytest algorithm/tests -q --ignore=algorithm/tests/test_traffic4cast.py
```

При выполнении тестов внутри готового production-образа используйте отдельный временный контейнер с `--user root`: Vite-тестам нужен доступ на запись к build-кэшу. Сам API продолжает работать от непривилегированного пользователя `node`.

Traffic4Cast проверяется отдельно при установленном необязательном `h5py`. На Windows задайте `PYTHONPATH` через `$env:PYTHONPATH='algorithm/src;algorithm/tools;.'` и выполните ту же команду pytest без префикса переменной.

Проверки браузера находятся в `site/scripts/check-*-browser.mjs`. Адрес отдельного стенда задаётся `BEEGO_QA_URL`, каталог результатов — `BEEGO_QA_OUTPUT`. Не используйте рабочую базу для тестовых публикаций. Изолированная конфигурация — `compose.transport-qa.yaml`; запускайте её с отдельным именем Compose-проекта и свободным портом.

## Изменения и данные

Рабочие данные размещаются в Docker volumes либо локальных игнорируемых каталогах. Не добавляйте их, секреты и автоматически созданные отчёты в коммит. Резервирование выполняет `site/scripts/backup-shifts.mjs`; проверяйте восстановление до удаления исходной копии.

Данные с контрольными суммами и проверенные планы — часть воспроизводимого комплекта. Менять их следует вместе с генератором, манифестом и независимой проверкой, а не массовым форматированием.

Правила интерфейса и публикации — в [site/AGENTS.md](../../site/AGENTS.md). Актуальная общая проверка — [validation.md](validation.md).

Проверки упаковки релиза: `python -m unittest discover -s deploy/tests -v` из корня. Упаковщик восстанавливает байты всех наборов с контрольными суммами; эта проверка защищает также перенесённые тестовые входы.
