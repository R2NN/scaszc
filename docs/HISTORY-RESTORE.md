# Восстановление прошлых смен

В рабочей локальной базе снова доступны **182 дня: 17.02–17.08.2026**, всего **30 644 заявки** с сохранёнными планами. Дату можно выбрать общим календарём в разделах «Заявки», «Инженеры» и «Ход смены».

## Причина и восстановление

После переноса версии рядом с приложением отсутствовал полный каталог `history/`. Аналитика читала свою сводку `site/public/data/analytics-history.json`, поэтому графики оставались доступны, а операционный API находил только 17 августа.

Существующий полный архив найден в `A:/BeeGo_MERGED_2026-09-29/history` — 181 предыдущая смена. Он подключён в `A:/BeeGo-tz3-emergency-dispatch/history` через Windows junction. Данные загружены штатным `site/scripts/seed-all-base-days.mjs` в используемую сервером базу `runtime/qa/tz3/ui.sqlite3`.

Новые дни и маршруты не генерировались. При загрузке штатный код сверяет независимо проверенные точные артефакты, их контрольные суммы со сводкой, исходные заявки, состав и геометрию каждого назначенного визита. Сохранённые ранее смены открываются без переиздания плана.

История остаётся модельной: это прежние синтетические входы с проверенными планами, а не подтверждённое фактическое выполнение. Отметки выполнения не создавались.

## Проверки

- Все 182 дня сначала загружены в отдельную проверочную базу, затем в рабочую. Для каждого дня сверены статус плана и количество заявок.
- Новый тест открывает первый, средний и последний архивный день через операционный API, проверяет координаты, дорожную геометрию, отсутствие выдуманных фактов и повторное открытие без новой ревизии. Базовая смена 17 августа остаётся неизменной. Оба теста `base-history.test.mjs` прошли.
- Через браузер проверены 16 августа и 17 февраля: календарь, заявки, состав, маршрут с остановками и «Ход смены».
- Сборка `pnpm build` прошла.
- Рабочие строки смен, версии, события, факты и аварийные решения сверены с резервной копией — не изменились. У часов сессий сохранены значения; серверные якорь времени/номер опроса и заполнение отсутствующих значений по умолчанию исключены из побайтового сравнения.

Доказательства: [сводка](evidence/history-restore/checks.json), [маршрут 16 августа](evidence/history-restore/aug16-orders.jpg). Резервная копия до восстановления: `runtime/qa/tz3/before-history-restore.sqlite3`.

## При переносе

SQLite и большой исходный архив игнорируются Git. Загруженные дни уже находятся в рабочей базе и доступны для просмотра независимо от повторного импорта. Для переноса на другой компьютер нужны резервная копия базы и полный `history/` для повторного импорта или пересчётов. Junction ссылается на локальный исходный архив, поэтому саму папку-источник нужно сохранить. Сводку аналитики нельзя использовать вместо полного операционного архива.
