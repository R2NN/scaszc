# Проверка сохранённых аварийных решений

Ветка: `codex/dispatch-artifact-replay`.

## Восстановление фактов

Отдельный инструмент `verify_dispatch_artifact.py` восстанавливает защищённые заявки, время освобождения инженеров и заблокированные маршруты из `dispatch_input` сохранённого артефакта. Расчёт и повторная проверка используют общую функцию интерпретации фактов. Проверки контрольных сумм исходного и нового планов сохранены; дополнительно проверяется соответствие захваченного ввода истории события и исходному плану.

Регрессионные тесты создают настоящие файлы исходного и рассчитанного планов, сериализуют маршрутные данные и контрольные суммы, затем заново открывают их отдельным проверяющим инструментом. Проверены раннее фактическое начало и просроченная незавершённая работа. Изменение факта без новой контрольной суммы отклоняется; изменение будущей поездки заблокированного инженера отклоняется даже с пересчитанной контрольной суммой файла.

## Сравнение после подтверждения

Карточка варианта и просмотр затронутого инженера получают исходный план из `shift.versions` по `candidate.baseRevision`. Новые варианты сохраняют также контрольную сумму исходного плана. Отсутствующая или несовпадающая исходная версия вызывает понятную ошибку вместо сравнения текущего плана с самим собой.

Тест выполняет поиск и настоящее подтверждение в `ShiftStore`, закрывает SQLite-базу, открывает её снова и сравнивает исходный план первой ревизии с опубликованным планом второй ревизии. Отдельно проверяется событие сравнения, отправленное настоящим React-контроллером после замены текущего плана, включая маршрут другого инженера и режим ближайшего действия.

## Результаты

- Node: 279 тестов прошли.
- Python: 228 тестов прошли, 2 пропущены.
- Production-сборка прошла.
- Сайт на `http://127.0.0.1:4200/` отвечает HTTP 200 и отдаёт новую клиентскую сборку. Перезапуск серверного процесса для нового поля контрольной суммы кандидата отклонён автоматической проверкой безопасности (`blocked by policy`). Сравнение ранее созданных кандидатов работает по сохранённому номеру ревизии; новое поле начнёт записываться после перезапуска сервера.
- Визуальная проверка не выполнена: инструмент браузера возвращает `Local browser use is disabled in Work settings`. Проверки данных карты и React-контроллера не заменяют визуальную проверку.
