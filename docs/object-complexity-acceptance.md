## Ограничения среды

Выполнена штатная попытка запуска Docker Desktop, но рабочий daemon получить не удалось. Контейнерная сборка не объявляется проверенной; Dockerfile дополнен новым каталогом данных, исключены локальные QA-БД и кеши. Дополнительные production-зависимости не добавлены.

Публичная дорожная материализация медленная: первая вставка подключения остановилась на 15 мин без публикации; последующая ограниченная вставка локальной заявки прошла. Для штатного интерактивного поиска нужен работающий локальный дорожный сервис либо явно настроенный endpoint.

Встроенный инструмент снимков размывает DOM-текст при виртуальном viewport, сохраняя карту. Стандартный и альтернативный захват, перезагрузка и проверка CSS не устранили проблему; другой подключённый браузер отсутствует (Chrome недоступен). Поэтому сохранённые браузерные снимки показывают композицию, но их мелкий текст не следует считать читаемым доказательством. Значения проверены через настоящий интерактивный DOM и действия; чёткая таблица PDF сохранена отдельно. Продуктовый CSS не менялся ради маскировки этой проблемы захвата.
