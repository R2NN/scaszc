# Материалы приёмки задания 3

Основной отчёт: [tz3-emergency-dispatch.md](../../tz3-emergency-dispatch.md).

`acceptance.json` связывает 10 полных планов, их входы/хеши, последствия, ручное и автоматическое решения. Сжатые исходные JSON лежат в `algorithm/artifacts/tz3/`. Для проверки нужно распаковать gzip без пересериализации JSON и запустить `algorithm/tools/verify_dispatch_artifact.py` с исходным dataset. Контрольные суммы gzip и распакованных байтов перечислены в acceptance.

Скриншоты:

- `baseline-shift.png`, `baseline-replan.png`, `baseline-dark-engineers.png` — исходный продукт;
- `incident-notification.png` — авария в существующем центре уведомлений;
- `search-dark-1280.png` — поиск и серверный таймер, 1280×720;
- `car-preview-dark.png`, `options-dark-1920.png` — сравнение и предпросмотр на одной карте;
- `manual-accepted-dark-1920.png` — сохранённый ручной выбор после reload, панель прокручена к изменениям.

Финальные новая светлая тема/узкое окно/экран автоматического принятия не сняты: доступ к локальному браузеру отключён настройками Work. Скриншоты не объявляются доказательством этих непроверенных состояний.
