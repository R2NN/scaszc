# Приближение к дому из списка времени

Кандидат: http://127.0.0.1:4199/. Ветка: `fix/focus-object-from-time-list`.

Нажатие на адрес открывает паспорт, плавно приближает карту до здания и выделяет точку кольцом. Камера учитывает фактические размеры обеих панелей и CSS zoom. При перекрытии панелей сворачивается только список; его фильтры сохраняются. Повторный выбор перемещает единственный маркер. «Показать на карте» в паспорте использует тот же механизм. Другие переходы в паспорт сами камеру не перемещают.

Проверено лично в браузере:

- Светлая и тёмная темы, 1280×720: дом между списком и паспортом, подпись видна.
- 900×1000: список сворачивается, точка остаётся слева от паспорта.
- Булатниковская, 4 к 1 и Кашира, Садовая, 18: приближение из общего вида, смена адреса и повторный выбор, в том числе Enter.
- Закрытие паспорта, повторное открытие списка: строка поиска сохраняется.
- Переключение на «Маршруты и заявки»: выделение времени скрывается; возврат сохраняет поиск.
- Один экземпляр карты и один маркер выделения в DOM.

Автоматически: 13/13 тестов (`object-time-focus`, `map-design`, `duration-transparency`); `pnpm build` успешно. Проверяются координаты, масштаб здания, пересчёт смещения при CSS zoom, обе панели, узкое окно, недопустимые координаты и сохранение более близкого масштаба.

Скриншоты: `desktop-light.jpg`, `desktop-dark.jpg`, `narrow-light.jpg`.

Данные, длительности и алгоритм планирования не менялись. `main` и исходный стенд 4188 не изменялись.
