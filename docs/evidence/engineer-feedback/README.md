# Обратная связь инженеров

Кандидат: http://127.0.0.1:4199/. Ветка `feat/engineer-duration-feedback`, исходный стенд 4188 и `main` сохранены.

## Где смотреть

«Заявки» → «Время на объектах» → найти Булатниковскую → открыть паспорт. Блок «Обратная связь инженеров» находится сразу под формулой времени. Ответ раскрывает план/факт, пояснение, подготовку, проверку повторяемости, решение, известные затронутые заявки и прошлые расчёты. Полные списки доступны через «Показать все»; отдельной вложенной прокрутки нет.

Данные для нового ответа вводятся в «Ход смены» → «Факт визита». Завершённое отклонение без комментария создаёт запрос пояснения; выполнение и реальные измерения сохраняются. Ответ можно дополнить в паспорте. Это внутренний процесс диспетчера; внешний канал связи с приложением инженера не подключался.

## Как принимается поправка

- Работы сравниваются по виду, составу и подтверждённой сущности. Технический остаток = измеренная работа минус расчёт по объёму. Доступ и ожидание клиента считаются отдельно.
- Неизвестные этапы, ручные длительности, ошибочные измерения, разовые и неустановленные причины не создают перенос.
- Требуются минимум четыре измерения, минимум два дня и два инженера. Для распространения на дом нужны разные линии, на одинаковые операции — минимум три объекта. Клиенты связываются через реестр лицевых счетов, не через совпадение адресов.
- Убираются выбросы; направление отклонения должно быть согласовано. Последние 20% наблюдений оставляются для временной проверки. Поправка должна улучшать ошибку относительно расчёта без истории и не ухудшать уже сохранённый адаптивный прогноз.
- Применяется осторожная оценка: медиана остатка × n / (n + shrinkage), в целых минутах. Параметры берутся из действующей версии модели. Поправки одного этапа не суммируются; действует наиболее конкретная пригодная особенность.
- Перед подтверждением сервер повторно проверяет данные и версию ответа. Прямой старый маршрут подтверждения не позволяет обойти проверку ответа инженера. Решения и ответы версионируются.
- Политика `feedback-evidence-v1` повторно проверяется при следующих оценках. Противоречивые свежие результаты, недостаток актуальных подтверждений, истечение срока или закрытие особенности прекращают её применение. Старые закрытые периоды не используются для автоматического восстановления причины.

## Данные и проверка

Добавлено 1822 синтетических ответа по существующим измерениям: разные пояснения для доступа, диагностики, упрощения работ, ожидания клиента и неустановленных причин, с точными этапами и номерами нарядов. Неизвестные причины не подменялись выдуманными техническими объяснениями. Повторный запуск дополнения идемпотентен; ответы оператора не перезаписываются.
