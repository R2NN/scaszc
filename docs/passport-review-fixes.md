## Изменения

1. Общая особенность: API возвращает данные исходных подтверждающих визитов, включая другие объекты. Редактор объединяет их с местными визитами без дублей, сохраняет режим при смене визита, заполняет описание и подготовку. Сохранение использует существующую проверку сопоставимости и замену особенности с аудитом; после успеха редактор закрывается.
2. Ссылка на визит: выбранная запись сразу включается в выдачу истории, получает выделение и фокус. Прокручивается только тело паспорта. «Показать ещё» продолжает выдачу после уже показанных записей.
3. Сводка: вместо 12 раскрытых категорий — три кнопки отбора и свёрнутый состав работ. Сводка и адреса находятся в одном прокручиваемом контейнере. Любой отбор применяется к источнику карты и списку одних и тех же объектов. Сброс группы возвращает все объекты.
4. Среднее: положительная ошибка делится на число визитов с превышением, отрицательная — на число визитов с сокращением, в том числе отдельно по видам работ. При отсутствии таких визитов среднее отсутствует. Интерфейс показывает два отдельных результата.
5. Стандартный объём: диагностика описана сегментами и площадкой, авария — площадкой, подключение и оборудование — устройством, точкой и площадкой, информационная работа — проверкой обращения. Состав группы различает повреждение, действие с оборудованием и посещение/поиск узла.
6. Аналитика: открытие паспорта сохраняет смонтированную исходную вкладку, её фильтры и прокрутку.
