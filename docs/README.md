## Статус комплекта

- Контрольная операционная смена: **17.08.2026**, 205 из 205 заявок в опубликованном плане, 32 задействованные бригады из 35.
- Сводная аналитика: **182 дня**, 17.02–17.08.2026. Полный операционный архив на стенде доступен для **одного дня**, 17.08.2026. Аналитический график и воспроизводимый архив — разные уровни данных.
- Недельные снимки МЦК/МЦД установлены на стенде. Для другого сценарного дня берётся эталон того же дня недели, а не расписание его исторической даты.
- Планы публикуются после независимой проверки; запрос на второй одновременный расчёт получает `429 PLANNING_BUSY`.

Для первичных формулировок используйте [условие задачи](../source_materials/original_inputs/условие%20задачи.md) и [консолидированный чек-лист](../site/docs/task-requirements.md). Файлы `START_HERE.md`, `README_TRANSFER_RU.md` и часть `site/docs/` сохраняют историю этапов разработки; их старые контрольные цифры относятся к предыдущим сборкам. Текущее состояние стенда и ограничения описаны в этом разделе.
