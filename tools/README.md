# Инструменты поставки

- `install_runtime_bundle.py` — проверяет и устанавливает комплектные дороги, транспортный индекс и исходники, включая перенос в Linux volumes Docker.
- `check_repository.py` — без сторонних зависимостей проверяет обязательные файлы, 115 записей контрольных сумм наборов, части runtime и сжатые входы домашнего сценария. Не изменяет данные.

Из корня репозитория:

```bash
python tools/check_repository.py
```

Полный запуск и состояние сервисов — в [инструкции](../docs/operations/quickstart.md). Инструменты разработки планировщика находятся отдельно в `algorithm/tools/`, серверные и браузерные — в `site/scripts/`.
