# Итог пересчёта по опубликованным нормативам

## Правила расчёта

- Момент из файла заявок — закрытое окно **начала работы**. Начать можно в любой момент внутри окна, включая границы.
- После начала выполняется полный норматив. Завершение может быть позже конца окна, если оно остаётся внутри смены специалиста.
- Справочные 20 минут дороги из `Нормативы.xlsx` не прибавляются.
- Дорога рассчитывается маршрутизатором отдельно.
- Буферы и коэффициенты времени не используются: множитель предварительной матрицы `1,0`, добавка `0`.
- Нормативы без дороги: подключение 70 минут, глобальная проблема 80, дозаказ 20, локальная заявка 30.
