# Данные проекта LCT2

Архив разделён на три части:

- `original_inputs/` — исходные файлы организаторов: ТЗ, нормативы, обезличенные данные, инструкции и расшифровка встречи;
- `prepared_dataset/` — подготовленный и проверенный набор данных схемы 2.1.0, который принимает алгоритм;
- `our_results/` — результаты наших расчётов: планы, перепланирование, объяснения, контрфактические сценарии и отчёты проверок.

Оригинальные файлы не изменены. Подготовленные данные и результаты вынесены отдельно, чтобы их нельзя было случайно перепутать с исходными материалами организаторов.
